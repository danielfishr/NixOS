# Repository Instructions

## Shortcut Documentation

When installing or uninstalling an application through this repository's
configuration, update the Shortcuts section in `README.md` in the same change:

- Add shortcuts configured for newly installed applications.
- Remove shortcuts belonging to uninstalled applications.
- Update existing entries when shortcut bindings change.
- Keep the available/unassigned Hyper shortcut list consistent with the
  configured bindings.
- Identify host-specific shortcuts and distinguish configured bindings from
  upstream defaults. Do not document unconfigured defaults as active shortcuts.
